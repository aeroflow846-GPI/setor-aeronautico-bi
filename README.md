# SETOR_AERONAUTIC_BI
Este API consistiu no desenvolvimento de um dashboard para o setor aeronáutico, contemplando a análise da distribuição setorial, geração de empregos, perfis sociodemográficos e evolução temporal dos indicadores. A solução foi construída com foco na visualização objetiva dos dados e no apoio à tomada de decisão baseada em informações quantitativas.

# SPRINT_1 
Na Sprint 2, avançamos com a base RAIS.
Entendemos o perfil dos colaboradores, a faixa salarial e o nível acadêmico do setor aeronáutico.
Os dados agora ajudam a entender melhor o setor e a planejar os próximos passos.

# SPRINT_2
Na Sprint 2, foi realizada a etapa de enriquecimento da base de dados utilizando a API do ViaCEP, permitindo a consulta automatizada de informações a partir dos CEPs cadastrados. Com o uso da linguagem SQL, os dados foram tratados, organizados e relacionados para obter o possível nome e localização das empresas vinculadas ao setor aeronáutico. Após o processamento, as informações foram consolidadas em uma planilha estruturada, servindo como base para análises posteriores e para a construção dos painéis de visualização do projeto.
